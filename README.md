# migracao-sei

Nota técnica operacional sobre a transição dos processos do e-CIGA para o SEI-Niterói, no
Departamento de Urbanismo (UDU/SMU Niterói). Base: Portaria SEXEC nº 044/2026 e a conferência
processo a processo do registro de distribuição do UDU em 27/11/2026.

**Nota publicada:** https://barboguim.github.io/migracao-sei/

| Arquivo | O que é |
|---|---|
| `index.html` | a nota, com o vídeo institucional embutido no player |
| `nota-tecnica.html` | mesmo conteúdo do `index.html`, para download direto |
| `nota-tecnica-migracao-eciga-sei.md` | o texto em Markdown, para gerar outras versões |
| `video-migracao-eciga-sei.mp4` | vídeo institucional "Transição de processo — do e-CIGA para o SEI-Niterói" |

Os dados de distribuição (responsável, caixa atual, órgão autuador, tempo parado) refletem a
conferência de 27/11/2026 e envelhecem à medida que os processos são tratados.
